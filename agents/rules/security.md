# Security & Restrictions

## Command Restrictions

- Do NOT run any shell commands outside the allowed list
- Do NOT execute scripts outside package.json

---

## System Restrictions

- Do NOT access system files
- Do NOT access or read .env files
- Do NOT expose secrets or sensitive data

---

## Package Restrictions

- Do NOT install new packages
- Do NOT modify dependencies without approval

---

## File Safety

- Do NOT delete files unless explicitly asked
- Do NOT modify config files unless required

---

## Notes

If a task requires actions outside allowed commands or permissions:
- Ask for approval first
